# SOURCE_POLICY — 출처·수집·검토·공개 규칙

## 허용 출처
- 학교알리미 Open API / 공시 항목, 나이스 교육정보 개방 포털 (기본정보·학과).
- 서울특별시교육청 고입자료실, 하이인포, 고입정보포털의 공식 자료.
- 학교 **공식** 홈페이지 문서 (도메인은 검증된 기본정보의 `homepage` 에서 얻는다). 블로그·학원·민간 요약·검색 스니펫은 사실 확정 근거가 아니다.
- 코드 허용 목록: `worker/urlguard.ts` `OFFICIAL_HOST_ALLOWLIST` + 학교 홈페이지 host(요청 시 동적 추가). 그 밖은 차단.

## 하지 않는 것
- 로그인·CAPTCHA·접근 통제 우회, 앱 프록시로 차단 우회, 임의 URL 범용 프록시.
- 재배포 권한 없는 파일의 공개 서버 복제 (`rights: restricted|link_only` 는 링크·메타데이터만).
- 상담 중 원격 크롤링·OCR 동기 실행. 사용자 요청 없는 자동 수집 스케줄·메일 알림.
- 학교명만으로 유형·과목·시설 추측, 비슷한 이름 학교 자동 병합, 비슷한 과목명 자동 동등 처리.

## 기준 시점 필드
공시연도, 문서 게시일, 적용 학년도, 대상 입학연도, 학년·학기, 수집일, 검토일은 별도 필드. 제목의 연도 하나로 판단하지 않는다 (2026 게시 문서가 2027 입학생 대상일 수 있음).

## 학교 유형 분류 규칙 (2026-10-17 감사 결과 반영)
- 상위 범주 `schoolType`(일반/자율형공립/자율형사립/특수목적/특성화/기타)은 **학교알리미 공시 종류(HS_KND_SC_NM)** 를 쓰고, '자율고등학교'는 공시의 설립 구분(사립→자율형 사립고, 공립·국립→자율형 공립고)으로 나눈다.
- 세부 구분 `schoolSubtype` 은 **나이스 SPCLY_PURPS_HS_ORD_NM 원문**(산업수요 맞춤형 고등학교=마이스터고, 외국어계열, 국제계열, 과학계열, 예술계열, 체육계열)을 그대로 저장하고 화면에는 '특수목적고 · 마이스터고'처럼 상위 범주와 함께 표시한다. 법령상 마이스터고는 특수목적고의 한 종류이므로 상위 범주를 바꾸지 않는다.
- 두 기관의 값이 다르면(예: 학교알리미 '일반고등학교' vs 나이스 '자율고') `schoolTypeStatus = conflict` 로 두고 `sourceConflicts` 에 두 원문을 함께 기록해 화면에 '자료 충돌' 배지와 두 값을 보여준다. 어느 쪽이 최신인지 사람이 확인하기 전에는 임의로 고르지 않는다. 공학 구분·설립도 같은 방식.
- 나이스 '전기/후기'(ENE_BFE_SEHF_SC_NM)는 `admission.period_raw` 사실로 원문 그대로 보관하며, 선발 주체(교육감 배정/학교장 선발)로 자동 변환하지 않는다. 선발 주체는 해당 연도 입학전형 규정을 등록했을 때만 표시한다.

## 출처 우선순위 (상황별, 하드코딩 금지)
- 모집요강: 해당 입학연도의 공식 **정정본/변경본** (`supersedesId` 로 이전 버전 대체, 이력 보존).
- 교육과정: 해당 **입학생·과정**의 최신 승인 문서. 원문끼리 충돌하면 `ruleStatus: conflict` 로 두고 검토 전 선택하지 않음.
- 규모 지표: 같은 기준(연도·정의·분모)의 공시만 비교.

## 처리 흐름
원문 등록(URL 확인/업로드: 서명·크기·MIME) → 로컬 추출(텍스트/표/좌표, HWPX 구조, XLSX 병합) → 후보 매핑(과목/학기/학점/선택군) → 일관성 검사(`publishChecks`) → **사람이 원문 옆에서 검토** → 명시적 승인(검토자 이름) → 공개(버전 있는 묶음, 트랜잭션). 자동 추출 = 초안. AI 보조 결과도 초안이며 자동 공개되지 않는다.

## 가상 자료
`isSynthetic=true` 레코드는 기능 검증 전용. 개발·테스트에서만 보이고 배포 환경에서는 가져오기·공개·조회가 모두 차단된다. 실제 학교명 아래 허구 과목·수치를 표시하지 않는다.

## 사용자 자료
상담 기록은 서버에 저장하지 않는다. 공개 공유 링크에는 학교 ID·입학연도만 담는다. 위치는 지도에서 찍은 대략적 좌표를 브라우저 메모리에만 둔다.
