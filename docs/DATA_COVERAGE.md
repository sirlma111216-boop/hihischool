## 자치구별
25개 구 모두 `not_attempted`. `npm run ingest:schoolinfo -- --post <url>` 실행 후 `/sources` 에서 성공/실패/학교 수/시각을 확인한다. 일부 구만 성공하면 앱은 '서울 전체'라고 표시하지 않는다.

## 학교알리미 어댑터의 미확인 사항
`scripts/ingest/schoolinfo.ts` 는 엔드포인트·apiType·키/시군구 파라미터 이름·응답 필드명을 `scripts/ingest/schoolinfo.config.json` 으로 덮어쓸 수 있게 했다. 기본값(`apiKey`, `apiType=0`, `sggCode`, `SCHUL_CODE`…)은 **공식 API 목록에서 재확인하기 전까지 가정**이다. 2026-01-01 이후 신규 키의 시군구 코드 조건은 공지(notice_no …256)로 확인했으나 코드 표 형식은 확인하지 않았다 (법정 시군구 5자리를 기본으로 두고 config 로 교체).

## 나이스
키 없이 실행하면 표본 행만 돌아오며 스크립트는 이를 `partial`/'표본' 으로 기록한다. NEIS 코드와 학교알리미 코드는 `school_codes` 에 provider 별로 분리 저장하고, 매핑은 주소·홈페이지·학교명 대조 후 `confirmed` 로 바꾼다.

## 교육과정 원문 (목표: 일반고 2 + 학교장 선발고/특성화고 1)
확보 절차: 학교 공식 홈페이지 또는 학교알리미 공시의 편제표 PDF/HWPX URL 을 관리 화면에 등록(허용 목록 검사) → 로컬 추출 → 패키지 → 검토. 파일 다운로드와 사람 검토는 운영자가 수행한다. 접근 실패는 `parse_status=not_retrieved` 와 사유로 남는다.

## 가상 fixture (기능 검증 전용)
`fixtures/synthetic.ts`: 가상 학교 A(2027 검토 완료·2026 참고, 선택군 G 3택1·H 학년 전체·X 교차 편성·K 자료 충돌·N 학점 미확인), B(2027, G 최대 2과목, M/O 규칙 없음), C(특성화, 2026 만, 학과 2개), D(2027 OCR 초안만). 문서 fixture: `tests/fixtures/syn-a-2027-table.pdf`(표지·목차·인쇄 쪽수·두 쪽 표·반복 머리글·다음 쪽 각주), `syn-c-2026-table.hwpx`(병합 셀), `syn-b-2027-table.xlsx`(병합 셀). 배포 환경에서는 모두 차단된다.

## 입학 규정
