## 학교 유형 감사 (2026-10-17, `npm run ingest:audit-types`)
학교알리미(HS_KND_SC_NM·FOND_SC_CODE)와 나이스(HS_SC_NM·SPCLY_PURPS_HS_ORD_NM·FOND_SC_NM·ENE_BFE_SEHF_SC_NM)를 323개교에 대해 나란히 비교했다.
- 일치: 일반고 186, 특성화고 68, 자율고(사립) 16, 특목고 21 — 특목고 세부: 외국어계열 6, 예술계열 6(국립 2 포함), 과학계열 3, **산업수요 맞춤형(마이스터고) 4**(서울도시과학기술고·서울로봇고·미림마이스터고·수도전기공업고), 국제계열 1, 체육계열 1. 세부 구분은 `school_subtype` 에 원문으로 저장하고 '특수목적고 · 마이스터고'처럼 표시한다.
- **유형 충돌 20곳**(학교알리미 '일반고등학교' vs 나이스 '자율고'): 공립 16(경동·경일·고척·광양·구현·당곡·대영·등촌·면목·서울여고·성동·솔샘·수락·원묵·중경·청량), 사립 4(동성·숭문·한가람·장훈). 어느 쪽이 최신 상태인지 확인 전까지 `schoolTypeStatus=conflict` 로 두고 두 값을 함께 표시한다 (서울시교육청 자공고 일반고 전환·자사고 전환 이력과 관련 가능성, 미확인).
- **공학 구분 충돌 2곳**: 성동글로벌경영고·경복비즈니스고 (학교알리미 '녀' vs 나이스 '남여공학').
- 나이스에 없는 학교 3곳: 성수공업고·도봉고·은일정보산업고(학교알리미 종류 공란 → 유형 미확인). 설립 구분 불일치 0건.
- 나이스 전기/후기 구분은 `admission.period_raw` 사실로 보관 (전기 86·후기 233 수준). 선발 주체로 자동 변환하지 않는다.

## 추출 방식별 검증
- **공식 웹페이지 HTML 표**(`scripts/docs/lib/htmlmatrix.ts`): 병합 셀(rowSpan/colSpan) 펼침, 학년×학기×이론/실습 열 매핑, 소계 행 분리·원문 합계 대조, '택n' rowSpan → 선택군 후보(unverified). 서울도시과학기술고 4개 표에서 보통/전문/이수 소계가 추출 합계와 일치함을 확인(표 4 의 괄호 학점 1건 제외).
- **PDF/HWPX/XLSX**: 가상 fixture 로만 검증. 가락고·강서고 PDF 는 다운로드 후 `npm run docs:extract` 로 처리 예정(실제 PDF 의 표 레이아웃이 fixture 와 다르면 `package-review` 의 열 인식 규칙을 보강해야 할 수 있음).

## 학교알리미 어댑터
공식 API 목록 페이지(학사/학생 > 학교기본정보, 2026-10-17 사용자 화면으로 확인)에서 요청 규격을 확인했다: 요청 URL `http://www.schoolinfo.go.kr/openApi.do`, REST/JSON, 요청인자 `apiKey`(필수), `apiType`(필수, 학교기본정보=0), `sidoCode`(선택), `sggCode`(선택, 첨부 '시도시군구코드.xlsx' 기준), `schulKndCode`(필수, 04=고등학교). 이용허락: 공공누리 출처표시. 어댑터 기본값(`apiKey`/`apiType=0`/`sggCode`/`schulKndCode=04`)과 일치한다. **미확인**: 서울의 `sidoCode`·구별 `sggCode` 값(첨부 xlsx 로 확인 필요 — 법정 코드와 다를 수 있음)과 응답 필드명(첫 실행 응답으로 `fieldMap` 조정). 키가 없어 아직 실행하지 않았다.
