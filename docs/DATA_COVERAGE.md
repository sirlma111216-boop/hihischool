## 추출 방식별 검증
- **공식 웹페이지 HTML 표**(`scripts/docs/lib/htmlmatrix.ts`): 병합 셀(rowSpan/colSpan) 펼침, 학년×학기×이론/실습 열 매핑, 소계 행 분리·원문 합계 대조, '택n' rowSpan → 선택군 후보(unverified). 서울도시과학기술고 4개 표에서 보통/전문/이수 소계가 추출 합계와 일치함을 확인(표 4 의 괄호 학점 1건 제외).
- **PDF/HWPX/XLSX**: 가상 fixture 로만 검증. 가락고·강서고 PDF 는 다운로드 후 `npm run docs:extract` 로 처리 예정(실제 PDF 의 표 레이아웃이 fixture 와 다르면 `package-review` 의 열 인식 규칙을 보강해야 할 수 있음).

## 학교알리미 어댑터의 미확인 사항
`scripts/ingest/schoolinfo.ts` 의 엔드포인트·apiType·키/시군구 파라미터·응답 필드명은 **공식 API 목록으로 재확인 전까지 가정**이며 `scripts/ingest/schoolinfo.config.json` 으로 덮어쓴다. 키가 없어 실행하지 않았다.

## 나이스
키 없이도 `SCHUL_NM` 정식명 조회는 해당 행을 돌려준다(`npm run ingest:neis -- --name <정식명>`). 전체 목록은 키가 있어야 받는다. NEIS 코드(SD_SCHUL_CODE)와 학교알리미 코드는 `school_codes` 에 provider 별로 분리 저장한다.

## 가상 fixture (기능 검증 전용)
`fixtures/synthetic.ts` 가상 학교 A/B/C/D 와 `tests/fixtures/*` 문서. 배포 환경에서는 차단된다.
