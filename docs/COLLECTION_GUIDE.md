# COLLECTION_GUIDE — 학교 홈페이지에서 받아올 자료와 넣는 방법

학교 기본정보·좌표·공시 지표는 API 로 들어오지만, **교육과정의 세부(과목·학기·학점·선택군)와 학교생활 정보는 학교가 홈페이지에 올린 문서에만 있습니다.** 이 문서는 학교별로 무엇을 받고 어떻게 넣는지 정리합니다. 받은 파일 목록 체크리스트: `data/checklists/download-checklist-2026-10-17.csv` (324행, 학교별 홈페이지 링크 포함).

## 우선순위

| 순위 | 자료 | 앱에서 쓰이는 곳 | 보통 있는 위치 |
| --- | --- | --- | --- |
| 1 | **교육과정 편제표 / 학점(단위) 배당표** — 대상 입학연도별 (2027 입학생이 아직 없으면 2026 입학생) | 6학기 매트릭스, 선택군 규칙, 조합 검토, 비교 | 교육활동 > 교육과정, 학교교육계획서 부록, 학교알리미 '교육과정 편성·운영' 첨부 |
| 2 | **선택과목 안내서 / 수강신청 안내** — 선택 개수·학점 범위·개설 조건(인원 충족 시), 공동교육과정·온라인학교 안내 | 선택군 규칙 확인(편제표 각주 보완), '편성 vs 개설' 구분, 학교에 확인할 질문 줄이기 | 교육과정 게시판, 진로진학, 공지 |
| 3 | **학교교육계획서**(해당 연도) — 특색사업·동아리·공동교육과정·방과후·기숙사·급식·장학·상담 계획 | 학교생활·지원 탭(계획/운영 결과 구분), 프로그램 검색 | 학교소개 > 교육계획서 |
| 4 | **신입생 모집요강 / 입학전형 요강**(학교장 선발고: 특목고·특성화고·자사고·마이스터고) — 전형 시기, 지원 자격, 서류, 일정 | 입학·일정 탭, 일정 겹침, ICS, 조건 대조 | 입학안내 > 전형요강 |
| 5 | 교육과정 **변경·정정 공고**(편제표 재공지) | 변경 이력(이전 버전 대체), 기존 상담의 재검토 알림 | 교육과정 게시판 최신 글 |
| 6 | 학과 소개(특성화고·마이스터고의 학과별 편제·취업 현황) | 학과/과정 선택, 비교 | 학과소개 |
| 7 | 학사일정 | (참고) 일정 | 학사일정 |

받지 않아도 되는 것: 홍보 영상, 사진, 학교 신문, 블로그·학원 요약. 학교 사진은 공식 허용 표시가 있을 때만 출처와 함께.

## 파일별로 함께 적어 둘 것 (근거 기록용)
- 받은 **공식 페이지 주소**(게시판 글 URL)와 받은 날짜
- 문서의 **대상 입학연도**(제목·본문에 '2027학년도 입학생'처럼 적힌 것) — 게시 연도와 다를 수 있음
- 특성화고·마이스터고는 **학과(과정) 이름**
- 정정본이면 이전 글 제목

## 넣는 방법
1. 파일을 `data/private/sources/<학교명>/` 에 둔다 (Git 제외). HWP 는 한컴오피스에서 PDF 또는 HWPX 로 저장해 넣는다.
2. 추출: `npm run docs:extract -- --file data/private/sources/<학교명>/<파일>.pdf --doc <문서ID> --out data/extracted/<이름>.json`
3. 패키지(학년×학기 매트릭스 표, 대부분의 편제표):
   `npm run docs:package-matrix -- --pdf data/extracted/<이름>.json --school <학교ID> --cohort 2027 --url "<공식 URL>" --publisher "<학교명>" --revision 2022 --post http://localhost:5173`
   학과별 표가 여러 개면 `--tracks "trk_a=정보보안과,trk_b=디자인과"` 로 표 제목과 과정을 연결한다. 세로형(과목|1학기|2학기) 표는 `npm run docs:package` 를 쓴다.
4. 관리 화면(`/admin` → 교육과정 버전)에서 원문 옆에 놓고 검토: 선택군의 선택 수·기간·예외, 학점 공란, 지정/선택, 유의사항. 검토자 이름으로 승인 → 공개.
5. 배포 DB 에 올릴 때: `npm run db:export-sql -- --out data/review/apply.sql data/review/<이름>.review.json` 후 `npx wrangler d1 execute highschool_atlas --remote --file data/review/apply.sql` (초안으로 들어가며 공개는 관리 화면에서).

학교 ID 는 체크리스트 CSV 의 '학교 ID' 열(학교알리미 코드 기반 `sch_si-S0100...`)을 쓴다.

## 지금까지의 실제 사례
- 서울도시과학기술고: 홈페이지 HTML 표 4개 → 초안 4건 (`docs:package-matrix --tables`)
